## Deployment blockers intentionally not hidden

1. Railway cannot read a Windows Unity folder. Use hosted knowledge (`SV13_KNOWLEDGE_BASE_URL`) or another deliberate deployment source.
2. SQLite publication state must live on a Railway Volume in production.
3. `AUTO_PUBLISH` remains off until guide layout/content has been reviewed.
4. Unity `ProjectIntegratedCandidate` is not proof of gameplay reachability; the bot keeps the existing public-status policy configurable.
