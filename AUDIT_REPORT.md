# SV13 Survivor Database — Final Pre-Railway Audit v0.1.2

The complete GitHub ZIP supplied immediately before Railway setup was audited.

## Repository issues found

The application source itself matched the previously repaired v0.1.1 code, but
the GitHub archive had three deployment/repository regressions:

1. `.env.example` was missing.
2. `.gitignore` was missing.
3. Generated `__pycache_` folders and `.pyc` files had been committed again.

The included `tools/repo_audit.py` correctly failed the uploaded repository for
those conditions.

A harmless but undesirable standalone line-continuation was also present in
`sv13bot/knowledge.py`; it parsed and ran, but was removed.

## v0.1.2 corrections

- Restored `.env.example`.
- Restored `.gitignore`.
- Removed generated bytecode/cache folders and unnecessary `.gitkeep` files.
- Removed the stray line-continuation in `knowledge.py`.
- Hardened manifest reload parsing.
- Hardened remote manifest file-name handling.
- Pinned `discord.py==2.7.1`.
- Pinned `python-dotenv==1.2.4`.
- Added `runtime.txt` pinned to Python `3.13.15`.
- Updated repository preflight to require the runtime pin.
- Bumped package version to `0.1.2`.
